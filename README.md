# Winter Siege deployment plan

Live page: https://raggylug233.github.io/winter-seige/

- `index.html` — which squads garrison each stronghold and who is Warden (generated by `build.py` from `data/squads.csv`)
- `balanced.html` — the alternative "one whale Warden everywhere" plan; `docs/comparison-gemini.md` compares both with the plan Gemini produced
- `docs/strategy.md` — why the layout is what it is
- `docs/research.md` — event rules and sources
- `sim.py` — layout simulator
- `battle.html` / `docs/battle-plan.md` — scouted enemy garrisons and our attack order (generated by `battle.py` from `data/enemy.csv`)
